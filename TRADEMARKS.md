# Utilisation du nom « Écluse »

Le code d'Écluse est publié sous licence Apache 2.0 : vous pouvez le copier,
le modifier et le redistribuer, y compris à des fins commerciales, en
respectant la licence (conservation de `LICENSE` et `NOTICE`, mention des
fichiers modifiés).

La licence n'accorde en revanche aucun droit sur le nom « Écluse » ni sur
ses logos (section 6 de la licence Apache 2.0). Pourquoi c'est important ici :
Écluse protège des données personnelles. Une version modifiée présentée sous
le même nom pourrait faire croire à des garanties qu'elle n'offre plus.

## Ce qui est permis

- Écrire « basé sur Écluse » ou « utilise Écluse » pour indiquer l'origine
  du code.
- Citer Écluse dans un article, une comparaison ou un benchmark.

## Ce qui ne l'est pas

- Appeler « Écluse » un fork ou une version modifiée, ou un nom qui s'y
  confond.
- Laisser entendre qu'un produit, un service ou un fork est la version
  officielle, ou qu'il est validé par le projet.

## Source officielle

La seule source officielle du projet est le dépôt
https://github.com/ecluse-dev/ecluse. En cas de doute sur une version ou un
usage du nom, ouvrez une issue sur ce dépôt.
