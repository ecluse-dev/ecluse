# P2-269 — Presidio rejoué sur 200 000 documents (mesure)

Type : `mesure`. **Rien n'est corrigé** ; `bench/ARTICLE.md` n'est pas touché.

## Ce qui a été rejoué, et avec quoi

- Corpus : `python3 bench/generate_corpus.py --n 200000 --seed 42` au commit
  `59f02e2` (main) : 200 000 documents, 183 532 entités annotées (nir 58 516,
  rpps 33 381, iban 50 111, finess 24 962, siren 16 562, adeli 0).
- Presidio **tel que livré** : `bench/run_presidio.py` sans option, soit seuil 0,35,
  modèle spaCy `en_core_web_lg` 3.8.0, `presidio-analyzer` 2.2.366, `spacy` 3.8.18,
  Python 3.13.18, reconnaisseurs par défaut seuls (aucun reconnaisseur écrit à
  la main : pas d'option `--recognizers`).
- Durée : **21 min 11 s** d'horloge (20 min 31 s de CPU), sur 2 cœurs, l'exécution
  partageant la machine avec d'autres mesures ; P2-262 avait extrapolé ≈ 30 min.
- Score : `bench/score.py` (tous types, types communs, ligne `siren`, fuite au
  caractère), commande exacte :
  `python3 score.py --corpus corpus200k.jsonl --pred "Presidio=pred_presidio200k.jsonl"`.

**Chemin mesuré** : Presidio seul (`AnalyzerEngine` par défaut). Aucun chiffre
d'Écluse n'est donné ici ; la comparaison porte uniquement sur les chiffres de
Presidio, rejoués contre le rescorage des prédictions du 21 novembre (`c3de6a8`)
sur l'annotation du 23 novembre.

## Incertitudes

- Les prédictions du 21 novembre ne sont pas versionnées : la comparaison porte
  sur les **chiffres** donnés par la fiche, pas sur un diff de fichiers de
  prédictions.
- Un seul rejeu, sur une machine à 2 cœurs partagés : la durée est indicative.
- Le corpus est synthétique : ces chiffres disent ce que fait Presidio par défaut
  sur des identifiants français que ses reconnaisseurs d'origine ne couvrent pas,
  pas ce qu'il ferait avec des reconnaisseurs écrits pour le français (P1-35).

## Reproduire

```bash
pip install presidio-analyzer==2.2.366
pip install https://github.com/explosion/spacy-models/releases/download/en_core_web_lg-3.8.0/en_core_web_lg-3.8.0-py3-none-any.whl
python3 bench/generate_corpus.py --n 200000 --seed 42 --out /tmp/corpus200k.jsonl
python3 bench/run_presidio.py --corpus /tmp/corpus200k.jsonl --out /tmp/pred_presidio200k.jsonl   # ≈ 21 min
(cd bench && python3 score.py --corpus /tmp/corpus200k.jsonl --pred "Presidio=/tmp/pred_presidio200k.jsonl")
```
