# P2-103 — Généralisation du lieu : effet de « département N » non relu (mesure)

Tâche `mesure` : rien n'est corrigé. Programme :
`packages/ecluse_redact/bin/run_generalisation_lieu_bench.dart`.

```bash
(cd packages/ecluse_redact && dart run bin/run_generalisation_lieu_bench.dart)
```

## Méthode

Le corpus de P2-93 ne généralisait jamais le lieu. On construit donc 810
documents synthétiques déterministes (aucune graine : produit cartésien de
listes fixes ; seules les communes sont réelles, géographie publique) :
27 communes (dont 10 petites) × gabarits « lieu seul », « lieu + âge »
(34, 58, 72, 91, 103 ans), « lieu + profession » et « lieu + âge +
profession ». Pour chaque document : `Ecluse.redact` avec référence, puis
`appliquerGeneralisations` avec la suggestion de **lieu** (retenue ou non :
l'appelant choisit), puis comparaison du F simulé (`fAfter` du candidat) au F
recalculé sur le texte généralisé.

## Résultats

| Mesure | Valeur |
|---|---:|
| Documents | 810 |
| Avec au moins une suggestion | 673 |
| Avec une suggestion de **lieu** | 24 |
| dont suggestion retenue (la première) sur le lieu | 12 |
| Gabarit des 24 | lieu + âge (24) |
| Refus à l'application | 0 |
| Texte généralisé contenant « département N » | 24 |
| QI lieu relu dans l'évaluation après application | **0 sur 24** |
| Statut après application | évalué 24 |
| Bande simulée (`fAfter`) | élevé 1, moyen 20, faible 3 |
| Bande recalculée | faible 24 |
| F recalculé > F simulé | 24 sur 24 |
| Rapport F recalculé / F simulé (médian) | 157 |

Exemple : « Elle a 103 ans et habite à Thionville. » → « Elle a 103 ans et
habite à département 57. » ; F avant 2,2 ; F simulé (âge exact, département
57) 55 ; F recalculé 3 638, qui est le F de l'âge seul sur la France entière.

## Constats

1. **Le lieu généralisé disparaît de l'estimation** : « département 57 » n'est
   pas relu (0 QI lieu sur 24). F est recalculé comme si aucun lieu n'était
   donné. Il est donc surestimé (médiane ×157 par rapport à la simulation) et
   la bande passe à « faible » (24 sur 24) alors que la simulation annonçait
   « moyen » dans 20 cas : le rapport recalculé rassure à tort. Le
   département reste pourtant dans le texte envoyé au tiers.
2. **Le lieu est rarement suggéré** : 24 documents sur 810, tous de gabarit
   lieu + âge. Dès qu'une profession est présente, le passage commune →
   département laisse F inchangé (le comptage des professions est déjà au
   niveau département, `estimator.dart`, cas A) : aucune suggestion de lieu.
   Un lieu seul, ou avec un âge courant, donne un F déjà « faible » et aucune
   suggestion. Le lieu n'est suggéré que pour un âge extrême (103 ans ici).
3. **Libellé** : le texte généralisé se lit « habite à département 57 » (la
   préposition reste devant). Lisible pour le tiers mais grammaticalement
   inexact ; non mesuré plus avant.

## Limites de la mesure

Corpus fabriqué pour produire le cas, pas représentatif de textes réels ;
24 cas, tous de même gabarit ; aucune vérité terrain sur la taille réelle d'une
classe d'équivalence (F). Le chiffre 157 est une médiane sur des âges de 103
ans pour la plupart.

## Libellé (P2-132, 6 novembre 2026)

`appliquerGeneralisations` réécrit la préposition qui précède un lieu
généralisé en département : « à » → « dans le », « de » / « d' » → « du ».
« Elle a 103 ans et habite à Rioz. » → « Elle a 103 ans et habite dans le
département 70. » Même mesure qu'au-dessus après le changement : 24 QI lieu
relus sur 24, F recalculé = F simulé dans les 24 cas, bandes identiques.
