- Tests Python du nouveau corpus (offsets, une forme par document, absence
  d'annotation sur les négations, préfixe stable, graine).

Annotation : une pathologie **de la personne** est annotée (DT2, ATCD :
diabète de type 2, fautes). Ne sont **pas** annotées : négations
(« non diabétique », « Diabète : non », « exclu », « Ni … ni … »),
hypothèses (« BPCO ? à éliminer », « Suspicion de … »). Les suspicions sont
rangées avec les négations par choix de mesure : la pathologie n'est pas
établie. À confirmer par le mainteneur.

## Lecture

1. **« non diabétique » fuit dans le mauvais sens (30/30)** : les formes
   adjectivales sont rattachées d'office et la négation « non » n'est pas
   dans la liste de P2-126. Risque : on signale, voire généralise, une
   pathologie que la personne n'a pas (faux positif, pas fuite).
2. **« DT2 » est manqué (30/30)** : le sigle n'est pas dans la table. C'est
   une **fuite** (pathologie réelle non signalée).
3. **« ATCD : » n'est pas une tournure de rattachement (30/30 manqués en
   lecture rattachée)** : fuite ; la mention est vue en brut.
4. Les négations placées **après** la mention (« : non », « exclu »,
   « ? à éliminer », « Suspicion de », « Ni … ni … ») ne sont pas
   rattachées faute de tournure précédente : 0 FP en lecture rattachée.
   Ce résultat tient à l'**absence** de rattachement, pas à une détection de
   la négation : si un rattachement plus large est ajouté (ex. « ATCD : »),
   ces formes deviennent à risque (« ATCD : diabète : non »).
5. **Les fautes simples sont couvertes** (« diabete » sans accent,
   « épilépsie »), parce que la comparaison normalise accents ; la limite
   n'est pas testée sur des fautes de lettres (« diabette », « epilepsy »).

## Ce que la mesure ne dit pas

- Une seule graine, un gabarit par forme, formes écrites par le projet :
  pas de fréquence réelle de ces écritures. Les 30 FN « DT2 » valent pour
  ce gabarit seulement.
- Table de pathologies non validée cliniquement (P2-110).
- « Suspicion » classée avec les négations : choix de mesure.
- Une mention par document ; les cas combinés (« non diabétique, ATCD : … »)
  ne sont pas mesurés.
