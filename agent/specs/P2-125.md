# P2-125 — Repérer les pathologies (mesure, non branché)

6 novembre 2026. Premier extracteur de pathologies, mesuré sur le corpus de
P2-112. **Il n'est branché ni sur le rapport de risque ni sur les
suggestions** : la table des pathologies fréquentes n'est pas validée
(P2-110) et aucune prévalence ne permet de chiffrer F.

## Ce qui est fait

`ecluse_reid` : `extrairePathologies(texte, catalogue:)` rend des
`PathologieMention` (bornes, catégorie, système, source `table` ou
`orphanet`, `rattachee`).

- **Sources** : table maison provisoire (copie de `P2-94-table.md` § 3 sans
  « SEP », `tablePathologiesProvisoire`) et `RareDiseaseCatalog` (Orphanet).
  La table prime à longueur égale (décision P2-113) ; la mention la plus
  longue l'emporte (« diabète de type 2 » plutôt que « diabète »).
- **Rattachement** : une mention est `rattachee` si une tournure comme
  « atteint(e) de », « suivi(e) pour », « antécédents », « diagnostic de »,
  « porteur de » la précède dans la même phrase.

## Mesure (`bin/run_pathologies_bench.dart`, appariement strict)

| | Brut | Rattachées seulement |
|---|---:|---:|
| corpus indices (397 mentions) : précision / rappel | 96,7 % / 96,7 % | 96,7 % / 96,7 % |
| catégorie juste (sur les mentions trouvées) | 100 % | 100 % |
| **faux positifs sur le témoin** (300 notes) | **208** | **0** |

- Les 13 erreurs des indices sont une seule : « myopathie de Duchenne »
  n'est pas une mention Orphanet en français (le nom est « dystrophie
  musculaire de Duchenne ») ; l'extracteur rend « myopathie » (table
  maison), d'où 13 FP et 13 FN.
- Sur le témoin, le repérage brut prend « réseau diabète », « unité
  Alzheimer », « prévention de l'AVC »… : le rattachement les écarte tous.
- Un écart de libellé de catégorie dans le corpus (VIH) a été corrigé dans
  `generate_corpus_pathologies.py` (catégorie juste : 98,7 % → 100 %).

## Ce que la mesure ne dit pas

- **Le résultat du rattachement est en partie construit** : les tournures
  cherchées sont celles des gabarits du corpus. Sur de vrais écrits
  (« diabétique », « DT2 », « pas de diabète connu »), le rappel sera plus
  bas et une négation sera prise pour une pathologie.
- Table non validée (P2-110) ; une seule graine.

## Suite proposée

1. Validation de la table (P2-110), puis régénération du corpus.
2. Négation (« pas de », « absence de ») et formes adjectivales
   (« diabétique », « épileptique ») : à mesurer d'abord sur un corpus qui
   les contient.
3. Branchement sur le rapport de risque comme « suggestion de dernier
   recours » sans F chiffré (`P2-94-table.md` § 5), après décision.
