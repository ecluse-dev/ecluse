# P2-287 — Mot courant lu comme commune dans le rapport de risque (mesure)

Type `mesure` : rien n'est corrigé. Chemin mesuré : `Ecluse.redact(..., riskReference:)`
(chemin du produit, rapport de risque inclus), via `packages/ecluse_redact/bin/run_qi_lieu.dart`.
Reproduire : `bash bench/mesure_qi_lieu.sh` puis `python3 bench/analyse_qi_lieu.py <dossier>`.
Données : synthétiques, graine 42. Le corpus « sans donnée personnelle » est tronqué à ses
60 000 premiers documents.

## 1. Ce que couvrent déjà `LIMITES.md`, P1-31, P2-136, P2-175

- **P1-31** : un nom de commune *ambigu* (plusieurs homonymes) est signalé, jamais « faible ».
  Cela ne concerne pas un mot courant lu comme *une* commune sans ambiguïté dans la référence
  (« Son » → F = 89, bande faible).
- **P2-136** : écarte les durées et les communes-mots courants *listés* (« Tours de garde »,
  forme « Tours » sans préposition). Le mécanisme est une liste, donc muet sur les autres mots.
- **P2-175** : écarte un patronyme homonyme *après civilité, titre ou métier*. Un mot courant en
  tête de phrase n'est pas couvert.
- `LIMITES.md` : ne mentionne pas le cas « mot courant en tête de phrase » (seule la mention
  P2-175 « reste possible » s'en approche). Le cas est donc **non documenté**.

Lecture : le lieu fantôme ne produit jamais une bande « élevé » sur ces corpus. Il fabrique

erreur d'*étiquette rassurante* (faux « faible »), pas d'alarme.

## 4. Sonde isolée (112 mots × 2 formes, en tête de phrase, texte sans autre QI)

15 mots sur 112 sont lus comme un lieu : Aucun (F = 267), Contre (135), Cours (195), Doux (102),
Fontaine (246), Grand (372), Long (590), Mont (37, bande moyen), Place (359), Rue (2 987),
Salles (191), Son (89), Vaux (310), Vers (234), Vieux (230). Tous en bande faible sauf « Mont ».
Tous sont capitalisés et en tête de phrase ; la forme minuscule (« son ») n'est jamais lue.
Le cas signalé (« Son », F = 89) est donc bien reproduit, mais en bande **faible**, pas élevé.

## 5. Sonde combinée (rapport réel : 45 ans, infirmière, Rioz, + une phrase)

Sans phrase : `evalue`, bande moyen, F = 31,6, lieux lus : Rioz. Avec une phrase commençant
par Son, Aucun, Mont, Cours, Salles, Vers ou Contre : `nonEvaluable`, aucune bande, lieux lus :
Rioz + le mot courant. **Un seul mot courant en début de phrase suffit à faire perdre le
rapport entier** (le rapport devient illisible au lieu d'être légèrement faux). Avec « son »
en minuscule : rapport inchangé.

## 6. Recommandation chiffrée

Deux correctifs simulés sur les sorties, sans modifier le code :

- **Exiger une préposition (« à », « de », « en »…) devant le lieu.** Perd 60 lieux légitimes sur
  396 (15 %) dans qi_adversarial (0 sur 320 dans qi_realiste) et n'écarte que 3 602 des 18 653
  lieux de mots courants (19 %) : « Salles », « La Réunion », « Linge » sont précédés d'une
  préposition dans les textes du corpus. **Déconseillé** : coût en rappel, gain faible.
- **Liste d'exclusion de 27 mots** (mots observés + sonde). 0 lieu légitime perdu sur les corpus
  de QI ; 18 653 sur 18 653 lieux de mots courants écartés. **Recommandé**, avec la réserve
  ci-dessous.
- **Statu quo** : possible, mais le coût est réel (cf. §5 : rapport entier perdu) et non
  documenté dans `LIMITES.md`.

Ordre proposé : (1) tâche `code` « liste d'exclusion de mots courants en tête de phrase pour les
lieux », extensible, avec la sonde `generate_sonde_mots_courants.py` comme jeu de test ;
(2) à défaut, ajouter la limite à `LIMITES.md`. Le choix revient au mainteneur.

## 7. Réserves

- **Circularité** : la liste de 27 mots est construite à partir des mots observés et de la sonde ;
  son score (0 perte, 100 % écartés) mesure ce qu'elle couvre, pas ce qu'elle manque. La sonde
  de 112 mots n'est pas exhaustive : toute liste laissera passer d'autres mots (« Fontaine »,
  « Vaux » sont aussi de vrais noms de lieux).
- **Corpus synthétiques** : « Salles », « La Réunion », « Linge », « ARS » viennent des
  générateurs du dépôt (corpus sans donnée personnelle), pas d'une distribution réelle ; les
  17 333 documents ne se lisent pas comme une fréquence réelle, seulement comme la preuve que le
  mécanisme existe. Dans les corpus de QI (légitimes), il n'y a aucun cas : le défaut n'y est
  pas mesurable.
- **Mots ambigus** : « Mont », « Fontaine », « Vaux », « Rue », « Place » sont des débuts de
  vrais noms de lieu. Une exclusion les ferait aussi perdre quand ils sont de vrais lieux.
- Le chiffre de bande « faible » pour « Son » (F = 89) est inférieur à la bande « élevé »
  (F < 10) : le défaut produit un faux rassurant, pas un faux alarmant.
